# Unclaimed Flexi Asia Automation

## Goal
Automate the monthly processing of unclaimed Flexi benefits for Indian employees.

## Problem
Each month, benefit files had to be prepared manually for submission to banks. This took roughly **3 hours** of manual work per cycle and was prone to human error.

## Solution
I worked as a developer on this project, under the direction of Marianita Ramirez, to automate the preparation of benefit files for banks. The automation generates the files from the source data, replacing the manual steps.

## Key results
- **Time reduced from about 3 hours to 5–10 minutes** per monthly cycle
- Consistent, repeatable output every month
