# SS Filipinas Payment Registration

## Description
Registers payment details for company codes 4113 and 4114 for selected paycodes during month-end close. The macro also prepares the journal entry so it is ready to submit.

## Key results
Saves about 3 hours of manual work per close and produces a journal entry ready for submission.
