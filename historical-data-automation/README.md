# Historical Data Automation

## Description
This project automates the collection of data needed for account reconciliations, so the team no longer depends on third parties to get the information. It runs in three stages:

1. **File generation:** Creates an updated People Cost file from the Blackline detail for the month being reconciled.
2. **Macro development:** Builds a macro that automatically retrieves the updated report for each reconciliation.
3. **Data population:** Fills each reconciliation with the relevant items and amounts for the accounts being reconciled.

The final flow adds the People Cost hierarchy and the SAP balance at the same time.

## Key results
- Removes the team's dependency on third parties for reconciliation data.
- Gives each reconciliation the current People Cost detail and SAP balance in one step.
