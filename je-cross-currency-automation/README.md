# JE Cross Currency Automation

## Description
Automates cross-currency journal entries for accounts that receive payment in one currency while their local currency is different. The tool also reads the SAP tab of the reconciliation, looks up each account, and determines whether an FX adjustment in SAP or a journal entry is needed. For journal entries, a button creates the entry and places it in a journal entry template.

## Key results
Saves an estimated 20 to 30 minutes per journal entry creation.
