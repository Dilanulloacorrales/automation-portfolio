# EHT Accrual Canada

## Description
Automates the journal entry process for Canada EHT (Employer Health Tax). A macro takes the EHT files from Global Payroll, splits the detail by company code, and creates the journal entry to post in the closing month. Developed in collaboration with a colleague.

## Key results
Saves about 1 hour of manual work per close.
