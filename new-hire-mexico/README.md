# New Hire Mexico

## Description
A macro for the Global Payroll team that submits new hire forms for Mexico to CloudPay with a single click. Used weekly, it has streamlined onboarding across LATAM, reduced manual effort, and reduced errors.

## Key results
Saves about 2.5 hours per month and supports regional standardization of onboarding.
