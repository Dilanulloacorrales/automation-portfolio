# IA Expat Roll Forward, Quarterly Automation

## Description
A macro that generates a quarterly summary of international assignment accruals, grouped by transaction type and year. It consolidates totals and subtotals, applies classification rules, runs quality checks, and keeps traceability to source details.

## Key results
Saves an estimated 2 hours per quarter and reduces error risk.
